### 왜 중계 서버를 쓰나

주가 시세 API는 브라우저에서 직접 부르면 CORS로 막히고, 학교·회사 네트워크는
금융 사이트를 카테고리째 차단하는 경우가 많습니다. 구글 앱스 스크립트가 대신
받아오면 두 문제가 함께 해결됩니다. 호출 주체가 구글 서버이기 때문입니다.

중계 서버 소스는 [`proxy/Code.gs`](proxy/Code.gs)에 있으며,
「세차방 오늘의 투자시황」(`market-now`)과 **같은 중계 서버를 함께 씁니다.**

- `?v=1` — 기존 core 응답(지수·ETF·원자재·코인). market-now가 쓰는 경로라 손대지 않습니다.
- `?v=2&only=plus` — 이 페이지가 추가로 쓰는 확장 응답(세계지수·종목·금리커브 + 뉴스 + 김치 프리미엄).

캐시는 시세 10분 / 암호화폐 5분 / 확장 시세 10분 / 뉴스 15분 / 김치 프리미엄 3분,
6개월 시계열은 6시간입니다. 야후가 큰 묶음 요청에서 일부 심볼을 흘리는 일이 있어
**12개씩 끊어 부르고, 빠진 것만 한 번 더 부른 뒤, 그래도 없으면 마지막 정상값**으로 채웁니다.

중계 서버가 응답하지 않아도 페이지는 내장 참고값으로 정상 표시되며,
값마다 `실시간` / `참고값` 배지로 구분됩니다.

## 공유 카드(OG)

카카오톡·SNS에 링크를 붙이면 `og.png`(1200×630)가 미리보기로 뜹니다.
이미지를 바꾸려면 같은 크기로 다시 만들어 `og.png`를 교체하면 됩니다.
카카오톡은 캐시가 강해서, 바꾼 뒤에도 옛 이미지가 보이면
[카카오 디버거](https://developers.kakao.com/tool/debugger/sharing)에서 캐시를 초기화하세요.

## 고치는 법

- **화면·계산**: `index.html` 하나만 고치면 됩니다. 빌드 도구 없음, 외부 스크립트 없음(폰트만 CDN).
- **시세 종목 추가**: `proxy/Code.gs`의 `SYM`(core) 또는 `SYM_X`(확장)에 `표시키: '야후심볼'`을 추가하고
  `clasp push` → 새 버전으로 **기존 배포 갱신**(URL 유지). 화면 쪽은 `WORLD_ASIA`·`US_STOCKS`·`KR_STOCKS`·`KR_ETFS` 배열에 한 줄 추가.
- **뉴스 주제 변경**: `proxy/Code.gs`의 `FEEDS` 검색어.
- **내장 참고값**: `index.html` 위쪽 `SNAP`, `ETFS`, `SNAP_DATE`.
